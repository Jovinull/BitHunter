## Regras de ouro
- **Escopo mínimo**: NÃO altere arquivos fora do escopo solicitado.
- **Zero refactors surpresa**: nunca refatore código que não foi pedido.
- **Build verde**: após toda alteração, garanta que o projeto compila sem erros.
- **Warnings**: corrija warnings nos arquivos que você tocou.
- **Sem inventar**: não crie métodos, classes ou sistemas que não foram pedidos.
- **Sem apagar**: nunca remova código/documentação existente sem autorização explícita.

## Commit e Push
- SEMPRE proponha um commit ao final (Conventional Commits).
- SEMPRE pergunte "Posso subir o commit?" antes de fazer push.
- Se o usuário disser "não", deixe tudo pronto localmente.
- ANTES de commitar: VERIFICAR que o projeto compila sem erros (javac)
- Ao receber autorização para subir:
  1. VERIFICAR compilação (se houver arquivos .java alterados)
  2. CRIAR uma branch nova (nome descritivo, ex: `feat/novo-monstro`, `fix/colisao-diagonal`)
  3. SEPARAR as mudanças em commits lógicos — cada commit agrupa arquivos que fazem sentido juntos
  4. FAZER push da branch
  5. FAZER merge da branch na main (--no-ff para preservar histórico)
  6. FAZER push da main
  7. DELETAR a branch (local + remote) após merge bem-sucedido
- Formato: `tipo(escopo): descrição curta`
  - Tipos: feat, fix, refactor, docs, style, test, chore, perf
  - Escopo: pacote ou sistema afetado (ex: entity, ui, tile, main)
- NUNCA commitar direto na main — sempre via branch + merge
- Para mais detalhes, consulte `docs/commit_policy.md`.

## Estrutura do projeto
- Linguagem: Java (sem build system — compilação manual com javac)
- Entry point: `main.Main`
- Game loop: `main.GamePanel`
- Pacotes: ai, bestiary, data, entity, environment, main, monster, object, pets, tile, tile_interactive, ui
- Resources: `resource/` (maps, lang, bestiary)
- Indentação: 2 espaços (conforme .editorconfig)
- Encoding: UTF-8, line endings: LF
- Para detalhes completos, consulte `docs/architecture.md` e `docs/code_style.md`.

- Classes: PascalCase

- Prefixos de classe: Mon (monstros), Obj (objetos), Npc (NPCs), It (tiles interativos)
